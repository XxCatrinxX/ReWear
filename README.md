# ♻️ ReWear

ReWear is a Progressive Web Application (PWA) focused on promoting sustainable fashion by allowing users to buy, sell, exchange, and donate second-hand clothing.

---

## Features

- User Authentication
- Complete User Profiles
- Marketplace
- Favorites
- Chat
- Offers
- Reviews
- Notifications
- Progressive Web App
- Responsive Design

---

## Technologies

### Backend

- Laravel 12
- PHP 8.2
- MySQL

### Frontend

- Blade
- TailwindCSS
- Alpine.js
- Vite

### Future

- PWA
- Push Notifications
- Offline Mode

---

## Installation

```bash
composer install

npm install

cp .env.example .env

php artisan key:generate

php artisan migrate

npm run dev

php artisan serve
```
